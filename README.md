# 🚨 CIVICFIX AI

### AI-Powered Smart Civic Complaint & Resolution Platform

> **Making civic complaint management smarter, faster, and more transparent with AI.**

## 🌆 About

**CIVICFIX AI** is a smart civic platform that helps citizens report public issues and assists authorities in analyzing, prioritizing, routing, and resolving complaints efficiently.

### 🔄 How It Works

**Citizen Report → AI Analysis → Priority → Department → Resolution → Tracking**

## ✨ Key Features

- 📝 Smart civic complaint reporting
- 🤖 AI-powered complaint & image analysis
- 🔴 Automatic priority detection
- 🏢 Smart department routing
- 🔍 Duplicate complaint detection
- 🖼️ Image evidence management
- 🗺️ Complaint map visualization
- 👨‍💼 Authority dashboard
- 🔄 Real-time complaint status tracking
- 🔔 Citizen notifications
- 📊 Complaint & department analytics
- 🤖 AI-generated complaint summaries

## 🧠 AI Technology

Powered by **Google Gemini AI** for:

**Image Analysis • Issue Detection • Severity Analysis • Recommendations • Complaint Summaries**

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript  
**Backend:** PHP  
**Database:** MySQL / MariaDB  
**AI:** Google Gemini API  
**Maps:** Leaflet.js + OpenStreetMap  
**Environment:** XAMPP
